# GITHUB
## demo git
- `git --version` : kiểm tra phiên bản
- `git config --global user.email"your_github_email"` email phải là mail github
- `git init` : khởi tạo sử dụng git cho dự an
- `git remote add origin duong_dan_https` : kết nối folder trong máy với repo 
- step 1:
    - `git add .`: thêm tắt cả file vào ds theo dõi
    - `git add <ten_file>`: thêm 1 file vào ds theo dõi
- step 2:
    - `git commit -m 'noi dung commit'`: chụp màn hình code ở thời điểm thao tác
